## Steps to embed a Bluesky post

First, find the URL of the Bluesky post

If you are looking at a feed of posts, you can find an individual post url in the date/time the post was published. To grab the URL, point your mouse to the date, using the right mouse click menu select Copy Link Address.

![Right click navigation of a date/time in Bluesky showing Copy Link Address option](https://wordpress.org/documentation/files/2026/04/Screenshot-2026-04-14-at-4.40.10-PM-1024x682.png)Next, edit your post or page and add a Bluesky Embed block.

![Editor view of adding a Bluesky Embed block using the block inserter](https://wordpress.org/documentation/files/2026/04/Screenshot-2026-04-14-at-4.31.58-PM.png)To add a Bluesky Embed block, click on the “Block Inserter” (+) and select the Bluesky Embed block.

You can also type `/bluesky` and hit enter in a new paragraph block to add one quickly.

[Detailed instructions on adding blocks](https://wordpress.org/documentation/article/adding-a-new-block/)

Then, Add the URL to the input that reads “Enter URL to embed here…” and press the Embed button

![Bluesky embed block with URL and Embed button](https://wordpress.org/documentation/files/2026/04/Screenshot-2026-04-14-at-4.43.19-PM-1024x424.png)If the URL is a link that can be successfully embedded, you will see a preview in your editor.

## Block toolbar

![Block toolbar for Bluesky Embed](https://wordpress.org/documentation/files/2026/04/block-toolbar-Screenshot-2026-04-15-at-1.34.27-PM.png)Every block comes with unique toolbar icons and block-specific user controls that allow you to manipulate the block right in the editor.

### Transform

![Block toolbar transforms for Bluesky Embed
](https://wordpress.org/documentation/files/2026/04/transform-Screenshot-2026-04-15-at-1.34.06-PM-1024x493.png)Transform the block to a paragraph, columns, details or group.

### Block moving tools

![Block moving tools for Bluesky embed block](https://wordpress.org/documentation/files/2026/04/block-moving-Screenshot-2026-04-15-at-1.34.27-PM-copy.png)The block-moving handles allow you to move the block up and down the editor. Use the six dots icon to drag and drop the block and place it anywhere on the page. Alternatively, click on the up and down arrows to move the block up or down.

[](https://wordpress.org/documentation/article/adding-a-new-block/)[Get more information about moving a block within the editor.](https://wordpress.org/documentation/article/moving-blocks/)

### Align

![Block align tool for Bluesky Embed block](https://wordpress.org/documentation/files/2026/04/align-block-toolbar-Screenshot-2026-04-15-at-1.34.27-PM-copy.png)Toggle the block between a none, wide-width display and a full-width display (if supported by your site’s theme).

### Caption

![Block caption tool for Bluesky Embed block](https://wordpress.org/documentation/files/2026/04/caption-block-toolbar-Screenshot-2026-04-15-at-1.34.27-PM-copy.png)If you wish to add a caption, click on the Add caption button on the Block toolbar. Then enter your caption text into the space below the Bluesky embed. You can remove the caption by toggling the caption button off.

### Edit URL

![Block edit URL toolbar for Bluesky embed block](https://wordpress.org/documentation/files/2026/04/url-block-toolbar-Screenshot-2026-04-15-at-1.34.27-PM-copy.png)Via the edit URL, you can change the Bluesky Embed URL in the embed block. Overwrite the existing URL and click on the “Embed” Button on the right.

### More options

These controls give you the option to copy, duplicate, and edit your block as HTML.

[Read about these and other settings.](https://wordpress.org/documentation/article/more-options/)

## Block settings

Every block has specific options in the editor sidebar in addition to the options found in the block toolbar. If you do not see the sidebar, simply click the settings icon next to the Publish or Save button.

![Block settings panel for Bluesky Embed block](https://wordpress.org/documentation/files/2026/04/Screenshot-2026-04-15-at-1.48.31-PM.png)### Dimensions

The Bluesky embed block provides dimension settings options to add margin.

[](https://wordpress.org/documentation/article/typography-settings-overview/)[Learn more about dimension controls.](https://wordpress.org/documentation/article/dimension-controls-overview/)

### Advanced

The advanced tab gives you the option to add a CSS class to your block, allowing you to write custom CSS and style the block as you see fit.

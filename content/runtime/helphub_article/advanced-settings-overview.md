Use Advanced Settings to further customize your block. While some of the options listed below apply to multiple blocks, others are block-specific. To learn more about a particular block, visit the [Blocks list page](https://wordpress.org/documentation/article/blocks-list/).

## How to access Advanced settings

If you don’t see the sidebar, click the **Settings** button next to Save/Publish. With your block selected in the editor, click the Advanced section in the Settings panel to expand its options.

![Editor location for Advanced block settings](https://wordpress.org/documentation/files/2026/05/593711403-5c6a21b5-a1c7-4146-bda9-bcc6f6e45ec1.png)[Read more about block settings.](https://wordpress.org/documentation/article/working-with-blocks/#block-settings)

## Common settings

### HTML anchor

![Advanced HTML Anchor setting](https://wordpress.org/documentation/files/2026/05/advanced-html-anchor.png)HTML anchor allows you to [make a unique web address](https://wordpress.org/documentation/article/page-jumps/) for a particular block. Then, you’ll be able to link directly to a block on your page.

### Additional CSS class(es)

![Advanced Additional CSS Class(es) setting](https://wordpress.org/documentation/files/2026/05/advanced-additional-css-classes.png)The Additional CSS class(es) lets you add CSS class(es) to your block, allowing you to write custom CSS and style the block as you see fit.

### Additional CSS

![Advanced Additional CSS option](https://wordpress.org/documentation/files/2026/05/advanced-additional-css.png)Additional CSS allows you to customize the appearance of the block. You do not need to include a CSS selector, just add the property and value, For example adding: `color: red;` will set the text color to red.

The field is only visible to users with the `edit_css` capability. [Learn more about WordPress user roles and capabilities.](https://wordpress.org/documentation/article/roles-and-capabilities/)

### HTML element

![Advanced HTML Element setting](https://wordpress.org/documentation/files/2026/05/advanced-html-element.png)Some blocks include a drop down to select the HTML element that wraps the block. This allows you to optimize your block content for screen readers and improve overall accessibility.

### Styles

![Advanced Styles setting](https://wordpress.org/documentation/files/2026/05/advanced-styles.png)You can also use the Apply globally button under styles to apply this block’s typography, spacing, dimensions, and color styles to all blocks of this type.

### Allowed blocks

![Advanced Allowed Blocks setting](https://wordpress.org/documentation/files/2026/05/advanced-allowed-blocks.png)Some blocks offer the option to specify which blocks are allowed inside of them. Click on the Manage allowed blocks button to make changes.

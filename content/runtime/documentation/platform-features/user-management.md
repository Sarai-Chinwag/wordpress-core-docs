WordPress.com makes it easy to manage who can access your site and what they’re allowed to do. Whether you’re working with developers, clients, editors, or other collaborators, you can invite new users, assign roles, and manage permissions—right from your site dashboard.

This page provides an overview of how user management works on WordPress.com. Use the links below to learn how to add users, understand user roles, transfer site ownership, and manage account access using WordPress.com’s secure sign-on system.

## Site ownership and managing multiple sites

Understand how site ownership works on WordPress.com and how to manage access across multiple sites. This guide covers transferring ownership, assigning roles, and keeping account details organized.

[Learn more](https://wordpress.com/support/invite-people/user-roles/)

## Invite people to your site

Find out how to invite new users to your WordPress.com site and assign them the appropriate role. This guide walks you through sending invitations and managing access for collaborators.

[Learn more](https://wordpress.com/support/invite-people/user-roles/)

## User roles

Learn about the different user roles available on WordPress.com and what each role can access or manage. This guide will help you choose the right level of access for each person you invite to your site.

[Learn more](https://wordpress.com/support/invite-people/user-roles/)

## Configure your site’s log in access

Learn how WordPress.com Secure Sign-On (SSO) works and how it connects user accounts for easier, more secure access. This guide explains how SSO enhances login security and simplifies user management.

[Learn more](https://wordpress.com/support/wordpress-com-secure-sign-on-sso/)

WP-CLI is the command-line interface for WordPress. You can do practically everything in your site’s dashboard with WP-CLI, from updating plugins and themes to creating new user accounts. Also, using WP-CLI gives you access to even more tools, like the ability to clear the WordPress cache or run custom PHP code to debug site issues.

This feature is available on sites with the [WordPress.com Business or Commerce plan](https://wordpress.com/hosting/?ref=developer-docs#pricing-grid).
